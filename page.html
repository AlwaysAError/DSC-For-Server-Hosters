● BUILDER
Server builder

Edit settings.json for defaults and plugins.js for the plugin source. This page writes the chosen plugins into server.cjs.

Paths

Each plugin is built by the builder, it will grab all required game hooks from the provided server.cjs file.

Plugins

Game Chat To Discord

Outputs in game text chat message's to a Discord webhook. Useful for moderation or letting your Discord server member's know what's happening in game.

Ranks

A highly customizable plugin which allows you to give player's in your server(s) custom ranks and EXP gains for said ranks. Multiple server's can share the same rank stats file as long as they are on the same VPS.

Timed Tooltips

Tooltip 1 is sent after it's delay, then tooltip 2 after it's own delay. Nothing is sent while the server is empty.

Website Chat

Displays the in-game chat on the server webpage along with allowing user's on the server webpage to send message's to those who are playing on your server.

Match Board

Displays a live leaderboard of the active match on the server webpage.

Ranks Board

Displays a custom leaderboard of either the ranks from the custom ranks plugin, a persons official DeadSwitch Combat account stats or both.

Live Map

(RAM and CPU intensive) Displays a live minimap on the server webpage that shows the active game map and player locations. You need to have DeadSwitch Combat installed on your server's VPS.

Map file's are read from this install. The server page shows where players are during a match.

RAGE Bots

(CPU intensive > AMD Ryzen 5 or higher recommended) Adds a new bot difficulty called "RAGE". These bots are unrestricted meaning they can play better than most high-skilled player's.
