DSC server builder

Share the whole folder. Do not send only dsc-builder.cjs.

Run
  Windows: double-click start.bat
  Linux:   sh start.sh
  Either:  node dsc-builder.cjs

That opens a page on this PC. Type the folder that contains server.cjs, pick plugins, then Write server.cjs. The old server.cjs is copied to server.cjs.bak-... first. The live map plugin asks for the game install folder.

Headless, using the saved settings.json:
  node dsc-builder.cjs --build

What to edit
  settings.json   paths, which plugins are on, EXP, ranks, tooltips, webhook
  plugins.js      the actual plugin code that gets pasted into server.cjs
  page.html       the setup page
  lib.js          how the file is scanned and written

Plugin options are written into server.cjs. Do not add dsc_levels_config.json or dsc_bots_config.json.
Player rank data is still dsc_levels.json.

A .exe is not included. Node is already required to run the dedicated server.
