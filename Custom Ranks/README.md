# Custom Ranks

Allows you to have your very own custom ranks for your DeadSwitch Combat server.

**Feature's**  
✰ Multi-server safe (more than one server can use the same level save file)  
✰ Ranking up  
✰ Rank demoting  
✰ Custom ranks  
✰ Custom EXP gains for: Kills, Assists, Deaths, Wins, Loss's, Friendly Fire (team hits)  
✰ Custom commands: /rank, /score, /top  
✰ Support for an infinite amount of ranks  
✰ Custom tip messages  
✰ Separate config from the default server config  

# How To Set Up
1. Download the provided .cjs file (the code for the plugin)  
2. Open the server file ``server.cjs``  
3. Copy the code from the provided file  
4. Paste the code at the bottom of the ``server.cjs`` file ON A NEW LINE  
5. Place the provided file called ``dsc_levels_config.json`` where the ``server.cjs`` file is located  
6. Configure the config file to your liking  

That's how easy it is
